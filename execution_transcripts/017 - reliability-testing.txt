017 – Reliability Testing: 5/5 Clean-Snapshot Runs

Date: 01/08/2026 | Time: 13:06:23
Procedure:

A reliability test runner (reliability.py) was implemented to automate the
full evidence requirement: restore a clean VM snapshot (clean-vulnerable-v3)
before each run, poll /health until the NetForge service responds, execute
the complete exploit chain via run_chain(), and record structured results.

The runner was executed for 5 consecutive iterations:

    python reliability.py http://192.168.77.21:8080 192.168.77.21

=== Summary: 5/5 runs succeeded ===

All 5 runs obtained both the user flag and root flag from a freshly
restored clean snapshot, and completed idempotent cleanup successfully.
Full run durations ranged from 3.09s to 4.38s. Structured results for all
5 runs, including per-run flags, timing, and cleanup status, were written
to reliability.json.

An earlier single-run dry test surfaced a Windows subprocess issue calling
the Vagrant CLI (list-form subprocess.run without shell=True hanging
indefinitely on the .bat wrapper); this was corrected by switching to
shell=True with an extended timeout before the 5-run test was executed.
